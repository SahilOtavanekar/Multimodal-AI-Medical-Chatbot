# Multimodal AI Medical Chatbot

## Overview

The Multimodal AI Medical Chatbot is an AI-powered health awareness
and symptom interpretation platform.

The application supports:

- Text-based conversations
- Medical image analysis
- Contextual conversation history
- Voice interaction
- Emergency detection
- Multilingual voice support
- Persistent chat history
- Secure authentication
- Medical safety guardrails

> The application is designed for health awareness and educational
> purposes. It is not a diagnostic system or a replacement for
> professional medical advice.

## Architecture

The application consists of:

- Next.js frontend
- FastAPI backend
- AI model integration
- Supabase authentication
- Supabase database
- Supabase storage
